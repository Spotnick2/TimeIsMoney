## #9 early smoke probe

A separate developer-only addon, **TimeIsMoneyProbe** (Probe/), installed by
Tools/deploy_probe.ps1 into `AddOns\TimeIsMoneyProbe`. It is not in the
TimeIsMoney TOC or package, and never reads or writes TimeIsMoneyDB. It loads the
Sim/ files with the client's embedded Lua, plus:

- `/timprobe env`: build, interface and the double behavior the simulation
  needs (2^53 + 1, negative zero, NaN, frexp/ldexp/fmod, decimal parsing of the
  halfway case 20614348053932190 and of 0.5400000000000001, `%d` width, bit library).
- `/timprobe math`: 1,223 JSMath cases (pow, sin, log10, toString) against V8's
  bit patterns (Probe/Vectors.lua, generated by tests/reference/probe_vectors.cjs).
- `/timprobe sim`: a fixed 2.5 s workshop run with computation, quantum chips,
  creativity, investments and a project purchase. It prints the state digest,
  which must equal the offline Lua 5.1 digest in Probe/Vectors.lua.
- `/timprobe icons`: Hearthstone 6948 (established item), Forever battery 274048
  and Alchemy 2259 (spell). Uses C_Item.GetItemIconByID / GetItemNameByID and
  C_Spell.GetSpellTexture / GetSpellInfo. Uncached items get
  C_Item.RequestLoadItemDataByID and GET_ITEM_INFO_RECEIVED with a 10 s timeout.
- `/timprobe save <text>` and `/timprobe status`: a TimeIsMoneyProbeDB marker plus
  a load counter read at ADDON_LOADED (the porting guide's sentinel pattern).

A creature model is deferred to #10: no verified display ID exists yet.
